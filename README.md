# RECOVR - Premium Gothic Massage & Wellness SPA

Plataforma integral para spa y masajes de alta gama con estética gótica, dividida en arquitectura desacoplada:

## Estructura del Repositorio

- **[`frontend/`](./frontend)**: Aplicación SPA desarrollada en Angular 19 con diseño Dark Gothic, SCSS modular, soporte para reservas, catálogo interactivo y panel administrativo.
- **[`backend/`](./backend)**: API REST construida en Java 21 con Spring Boot, Spring Security, JPA/Hibernate, MySQL y documentación OpenAPI / Swagger. Incluye configuración de Docker Compose para base de datos local.
- **[`exposicion/`](./exposicion)**: Material de sustentaciones académicas, documentación de entregas, especificaciones, diapositivas y guías de roles organizado por avances:
  - `avanze1/`: Primer entregable y sustentación técnica (APF1, diapositivas, mapas de API, guías por integrante).
  - `avanze2/`: Segundo entregable.
  - `avanze3/`: Tercer entregable final.
